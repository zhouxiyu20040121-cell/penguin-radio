# 十上无难事·点歌台 · 独立部署说明

这个文件夹里只有一个文件：`index.html`（单文件应用，CSS/JS 全部内联，图片走公开链接，无需构建、无需外部依赖）。
放到任意静态托管上即可得到一个没有平台角标、可自由分享的链接。

## 一、当前云端架构（腾讯云 CloudBase）

- **数据库**：CloudBase PostgreSQL（PostgREST 网关），公共 schema 下三张表：
  - `tracks`：`id` 主键 + `doc`（jsonb，整条投稿）
  - `accounts`：`sid` 主键 + `doc`（jsonb，账号资料）
  - `app_meta`：`key` 主键 + `value`（jsonb，存 `wipeAt` 清空时间点）
- **鉴权**：网页端匿名登录（`/auth/v1/signin/anonymously`，请求头带 `x-device-id`），拿到 JWT 后以 `anon` 角色读写；三张表均已开启 RLS 并对 `anon` / `authenticated` 放行，同时做了表级 GRANT。
- **令牌**：access_token 有效期 2 小时，本地缓存、临期自动重签；遇 401 强制重签一次后重试。
- **容错**：所有请求带超时（AbortController）与指数退避重试；本机保存影子副本，读失败时不删本地数据，恢复后自动补传。

## 二、托管与安全域名

- 应用现托管在 CloudBase 静态网站托管，默认域名形如
  `https://<envId>-<appid>.tcloudbaseapp.com/`，该域名默认在 WEB 安全域名白名单内，可直接调网关。
- 免费体验版**不支持自行添加 WEB 安全域名**，因此把页面放到其他域名（如 GitHub Pages）时，浏览器会因来源域名不在白名单而被网关拒绝（403）。
- 默认域名仅限开发测试，有访问频率限制；要绑定自定义域名或加白名单，需升级付费套餐。

## 三、其他可用托管方式

- **CloudBase 静态托管（当前方案，推荐）**：控制台直接上传 `index.html` 即可。
- **Vercel / Netlify**：拖入控制台得到 `*.vercel.app` / `*.netlify.app`，但需把对应域名加入网关白名单（付费）。
- **对象存储静态网站**：阿里云 OSS、腾讯云 COS 等；注意 2024 年后新建 COS 桶默认域名强制下载，浏览器无法直接预览。

## 四、需要注意的限制

- 免费体验环境有效期约 6 个月，到期前需手动续期；届时不续期数据可能被回收。
- 登录是「学号 + 名字」，无密码校验，属于内部熟人场景的轻量方案，不适合放敏感信息。
- 企鹅与吉祥鹅图片托管在 `media.doubao.com`，需能访问该域名；若部署环境访问不到，可改为内联打包。
