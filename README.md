# 十上无难事·点歌台 · 独立部署说明

这个文件夹里只有一个文件：`index.html`（单文件应用，CSS/JS/图片全部内联或用公开链接，不需要别的依赖）。
把它放到任意静态托管上，就能得到一个没有平台角标、可以自由分享的链接。

## 一、最快的上线方式（推荐 GitHub Pages）

1. 注册/登录 GitHub，新建一个仓库，名字随意（例如 `penguin-radio`），设为 Public。
2. 把 `index.html` 上传到仓库根目录（网页上「Add file → Upload files」即可）。
3. 进入仓库 Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main` / 根目录，保存。
4. 等 1～2 分钟，得到地址：`https://<你的用户名>.github.io/penguin-radio/`
5. 在微信里发这个地址即可；国内访问 GitHub Pages 偶尔慢，但不影响打开。

## 二、其他可用方式

- **Vercel / Netlify**：把文件夹拖进它们的网页控制台，自动得到一个 `*.vercel.app` / `*.netlify.app` 链接。
- **学校/社团服务器、对象存储静态网站**（阿里云 OSS、腾讯云 COS、七牛）：上传 index.html，开启「静态网站」功能即可。
- 只要能让浏览器直接打开这个 html，就算成功，不需要 PHP/数据库。

## 三、换域名后要做的两件事

1. **重新生成海报二维码**：现在海报里那张二维码指向的是原来的豆包链接。拿到新域名后，把新地址告诉我，我帮你重新出一张海报/二维码。
2. 老链接里的投稿数据不用搬：账号和投稿都存在云端 bucket（`kvdb.io`），换域名不影响同一个账号看到同一批歌。

## 四、需要注意的限制（重要）

- 云端存储用的是免费公开桶：拿到 bucket 链接的人理论上可以读写；长期完全不活跃（约一个月）时，免费服务可能会清理数据。要长期稳定，建议换成自己的数据库（我可以按你选的平台改）。
- 页面里的企鹅和吉祥鹅图片托管在 `media.doubao.com`，需要能访问该域名；若你的部署环境访问不到，告诉我，我把图片打包进 html 内联。
- 登录是「学号 + 名字」，没有密码校验，属于内部熟人场景的轻量方案，不适合放敏感信息。

## 五、想改成微信小程序

需要小程序主体（个人/学校/社团）+ AppID + 备案。你有 AppID 后告诉我，我把同样的界面打包成小程序版本。
